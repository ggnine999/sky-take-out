# 苍穹外卖

基于 [shuhongfan/sky-take-out](https://github.com/shuhongfan/sky-take-out) 的项目代码改进版，保留来源说明及项目内已有许可文件。

## 项目目录

- `sky-take-out/`：Java 后端、回归测试和运营报表模板。
- `project-rjwm-admin-vue-ts/`：Vue 管理端源码及测试。
- `mp-weixin/`：小程序编译产物及服务器地址配置（原始 UniApp 工程未包含在源仓库中）。
- `nginx-1.20.2/conf/`：反向代理配置，需自行安装 Nginx、配置静态目录和 HTTPS。

配置、构建、验证及尚未完成的上线事项见 [IMPROVEMENTS.md](IMPROVEMENTS.md)。不要将真实密钥、证书或本地环境配置提交到仓库。

## 发布范围

本发布版本采用独立初始提交，不包含原仓库历史。课程资料、讲义、PPT、旧项目副本、示例工程、IDE 配置、旧前端构建产物及服务程序二进制不在发布范围内。它们保留在原本地工作目录，不随此版本上传。

历史凭据应在对应平台撤销或轮换；不上传历史记录并不能使旧凭据失效。数据库初始化结构需从可信的原项目资料获得，导入前请自行检查示例账户和数据。
